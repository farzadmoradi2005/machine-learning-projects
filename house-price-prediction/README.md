
# House Price Prediction using Random Forest

## Overview

This project predicts house prices using the Random Forest Regression algorithm.

## Dataset

The dataset contains information about houses such as:

- Area
- Address
- Price
- Other property features

## Project Steps

1. Load the dataset
2. Data cleaning
3. Remove missing values
4. Detect outliers using Box Plot
5. Feature engineering
6. Train Random Forest Regressor
7. Evaluate the model

## Libraries

- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## Model

Random Forest Regressor

## Results

The model predicts house prices based on property characteristics.
