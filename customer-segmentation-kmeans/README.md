
# Customer Segmentation using K-Means

## Overview

This project groups customers into different clusters using the K-Means clustering algorithm.

## Dataset

The dataset contains customer information such as:

- Gender
- Age
- Income
- Spending Score

## Project Steps

1. Load the dataset
2. Data preprocessing
3. Encode categorical features
4. Standardize numerical features
5. Apply K-Means
6. Visualize customer clusters

## Libraries

- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## Model

K-Means Clustering

## Results

Customers are grouped into similar behavioral segments.
