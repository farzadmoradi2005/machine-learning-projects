# Heart Disease Prediction

## Overview

This project predicts whether a patient has heart disease using Logistic Regression.

## Dataset

The dataset contains medical attributes such as:

- Age
- Sex
- Blood Pressure
- Cholesterol
- Chest Pain
- Heart Disease

## Project Steps

1. Load the dataset
2. Exploratory Data Analysis (EDA)
3. Correlation analysis
4. Train-test split
5. Train Logistic Regression model
6. Evaluate the model

## Libraries

- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## Model

Logistic Regression

## Results

The model predicts whether a patient is likely to have heart disease.
