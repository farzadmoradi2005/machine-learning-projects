
# Movie Recommendation System

## Overview

This project implements a content-based movie recommendation system using cosine similarity.

## Dataset

- movies.csv
- ratings.csv

## Project Steps

1. Load movie and rating datasets
2. Perform exploratory data analysis (EDA)
3. Prepare the data
4. Calculate cosine similarity
5. Recommend similar movies

## Libraries

- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## Algorithm

Cosine Similarity

## Output

Given a movie, the system recommends similar movies based on user ratings.
